## 关节角度标准

### 公路车（Retül 动态测量）

| 关节角度 | 爱好者范围 | 职业范围 |
|---------|-----------|---------|
| 膝关节伸展角（下死点） | 35-40° | 30° |
| 膝关节弯曲角（上死点） | 108-112° | — |
| 髋关节角度 | 55-70° | — |
| 肘关节角度 | 150-170° | — |
| 躯干角度 | 45-55° | 35° |

> 膝关节伸展角度的另一种表述：140-145° = 与完全伸直（180°）相差 35-40°

### 车型对比

| 参数 | 公路车 | 山地车 | 计时赛 | 铁三车 |
|-----|-------|-------|-------|-------|
| 膝盖弯曲角 | 108-112° | 110-115° | 110-115° | 110-115° |
| 膝盖伸展角 | 35-40° | 35-40° | 37-42° | 37-42° |
| 背部角度 | 45° | 50° | 20° | 25° |
| 肘部角度 | 150-170° | — | 90-100° | 90-100° |
| 最小髋关节角度 | — | — | 35-45° | 35-45° |
| 踝关节角度范围 | — | — | 15-30° | 15-30° |

## 车座设定

### 车座高度

**窗口概念**：车座高度不是单一完美值，而是一个可接受范围（窗口）。灵活性差时偏下限，灵活性好时偏上限。

**设定方法对比**：

| 方法 | 步骤 | 优缺点 |
|-----|------|--------|
| 脚后跟对脚踏法（静态） | 下死点脚后跟踩脚踏中心，膝盖完全伸直 | 新手适用；忽略锁鞋/锁片/踩踏风格 |
| 胯高×0.883 公式法 | 五通沿立管到车座顶端距离 = 胯高×0.883 | 假设所有人比例相同；对非标准体型失效 |
| 测角法（静态） | 大转子-膝盖旋转中心-踝关节外骨块，目标 25-35° | 静态不模拟实际骑行 |
| 动态 Retül 法 | 15秒采集 10000+ 数据点求平均 | 黄金标准 |

**关键原则**：
- 功率最优高度靠近窗口上限（膝关节伸展 25-30°），但受腘绳肌灵活性限制
- 车座太低 → 髌骨压力增大
- 车座太高 → 膝盖过度伸展、腘绳肌问题
- 安全舒适区瞄准窗口中间位置
- 踩踏风格影响：脚尖朝下车手可比脚后跟下沉车手设更高车座

### 车座后移量

- 太靠后 → 踩踏难发力 + 前端操控变轻（危险）
- 太靠前 → 髌骨压力大 + 手掌手腕受压（尺骨神经病变）
- KOPS 法（静态）：3点钟方向膝盖与脚踏轴心垂直对齐仅是历史参考，不是所有车手必须达到的目标
- 动态 Retül：结合骨盆、膝盖和足部实际运动轨迹评估；膝盖位于脚踏轴线前/后不是单一安全判据
- 车座过于靠后等效于提高车座高度

### 车座角度

- 常见起始参考：承重区接近水平；若需要轻微鼻端下倾，应以坐垫设计和体感小幅验证，而不是强制固定2°
- 鼻端朝上通常是错误弥补（应纠正车座高度或前后平衡）
- 鼻端朝下 → 骨盆前旋 → 背部更平 → 更气动，但增加手臂压力
- UCI 规定水平（业余不必遵守），允许向下 2.5° + 0.5° 偏差

### 车座舒适度

- 女性臀部问题比男性多且严重
- 坐骨结节间距决定车座宽度选择
- 老手轻松长距离骑行更易臀部疼痛（踩踏力度小→体重更多压在车座）
- 中空车座对男性更有效（缓解中间压迫），对女性可能加重问题
- ISM Adamo 车座成功靠活动臂随踩踏弯曲旋转，非缺口本身

## 车把设定

### 宽度

- 等于肩宽（肩峰间距）
- 过宽 → 疲劳 + 手掌麻木 + 转弯慢
- 过窄 → 肱三头肌疲劳 + 转弯过于敏感

### 落差与前伸量

- **落差**：车座顶端到车把垂直距离
- **前伸量**：车座鼻端到车把水平距离
- 取决于：车架 stack/reach、把立高度/长度、车把形状
- 长臂车手偏好深车把（大落差长前伸）
- 前伸能力差者偏好短浅车把
- 把立长度正常 10-12cm；短于 10cm 或长于 14cm → 车架尺寸可能不对

### 刹把位置

- 应让握手变头和下把时均能自如刹车
- 简单方法：刹把末端与下把末端齐平
- 若需靠上才舒适 → 前伸量和落差太大
- 山地车刹把：手腕-手臂成一条线（30-40°）

### 设定建议

- 从较高位置开始 → 手臂放松 → 肘部微弯 → 轻松抬头看路 → 无颈肩紧张
- 逐渐调低而非一步到位
- 单车可快速调整，身体适应需长时间

### 计时赛/铁三车把

- 伸展把稍微向上倾斜有助于稳定身体避免前滑
- 手和手腕应保持放松，紧绷说明上肢其他位置有问题
- 肘垫应在肘部或附近承受重量；太靠前增加手臂/肩膀/颈部疲劳
- 窄臂位更气动但肩背肌肉负荷更大；宽臂位减少肌肉负荷
- UCI：伸展把须符合 1:3 比例且固定不可调

## 锁片与脚踏设定

### 锁片前后位置

| 方法 | 描述 |
|-----|------|
| 通用法则 | 3 点钟方向跖骨球对齐脚踏轴心中心线 |
| 托德·卡佛法 | 脚踏轴心位于第一/第五跖骨顶端中间，更有效 |

- 锁片靠前（脚靠后）→ 脚后跟力臂更长 → 更多上下运动 → 跟腱问题
- 锁片靠后（脚靠前）→ 压力分布更大脚掌区域 → 缓解"热脚"

### 锁片旋转

- 按个人下肢生物力学特征（走路姿势）设定
- 脚掌朝前者：锁片垂直朝前
- 外八字脚：按外八字设定，常需向五通方向移动锁片或使用更长脚踏轴心
- 内八字脚：按自身生物力学设定，注意对非内八字者会引起髂胫束问题

### 浮动量

- 浮动 = 锁片允许的少量旋转移动
- 仅 1° 自由浮动即可显著减少膝关节负荷
- 外翻（非内翻）前脚掌能减少膝关节负荷
- 浮动类型：
  - 脚趾浮动（Look/Shimano）：前端为中心旋转
  - 中心旋转（Speedplay）：以跖骨球为中心
  - 弹簧回中（Shimano Dura Ace）
  - 摩擦力回中
- Speedplay 适合脚踏设定困难者（高度可调节、更长轴心选项）

### 站立阔度与 Q 因素

- Q 因素 = 两曲柄间距离
- Q 角度 = 股四头肌与髌骨肌腱所成角度（女性因骨盆更宽而更大）
- 髋窄者锁片装外侧缩小站立阔度，髋宽者反之
- Speedplay 可左右各调 4mm，提供 4 种轴心长度

### 垫片使用

- "80% 的人前脚掌内翻"说法被大大高估，真正前脚掌内翻很罕见
- 除非有医学理由或日常已使用矫正装备，否则不应使用垫片
- 外翻足垫片适用者不到 10%

## 常见疼痛诊断表

### 脚部

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 脚痛/麻木 | 鞋太紧过小 | 确认鞋码和鞋形 |
| 跖骨球痛 | 锁片位置问题 | 调整锁片 |
| "热脚"（麻木刺痛） | 鞋过小过紧、脚肿胀 | 确认鞋码、锁片后移 |
| 瀑布效应 | 锁片过于靠内侧致脚外侧下压 | 纠正锁片位置或加长脚踏轴心 |
| 抽筋 | 鞋太大或太小 | 确认鞋码 |
| 足弓疼痛 | 足姿相关、扁平足过度内旋 | 矫形鞋垫 |
| 跟腱疼痛 | 车座高低、连续爬坡、锁片位置 | 调整车座高度、锁片后移 |

### 膝盖

| 位置 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 膝前痛 | 车座太低/太靠前、锁片过于靠前 | 升高/后移车座、调整锁片 |
| 膝后/外侧痛 | 车座太高 | 降低车座 |
| 膝内侧痛 | 站立阔度不当 | 调整锁片/脚踏轴心 |
| 膝外侧（髂胫束） | 车座太高/太靠后、Q 角度不当 | 降低/前移车座、泡沫轴 |

**黄金法则**：一次只改变一项设定

### 腰部

| 可能原因 | 解决方案 |
|---------|---------|
| 车座太高 → 臀部摇摆 | 降低车座 |
| 前伸量过大 → 躯干过度弯曲 | 缩短把立或升高车把 |
| 极端鼻端下倾10–15° | 某项早期研究在特定群体报告腰痛改善，但**不得作为常规设置**；明显下倾可能使身体前滑、手腕承重及麻木加剧。应优先检查整体骑姿，并在专业人员指导下逐步小幅调节 |
| 腘绳肌紧绷 → 骨盆后拉 | 拉伸腘绳肌 |
| 车座伤害致代偿姿势 | 检查车座角度和舒适度 |

### 颈部

| 可能原因 | 解决方案 |
|---------|---------|
| 车把落差过大（最常见） | 升高车把 |
| 长距离骑行颈部耐力不足 | 逐步适应、锻炼颈部耐力 |

### 手与手指

| 神经 | 症状 | 可能原因 | 解决方案 |
|-----|------|---------|---------|
| 尺神经 | 小指/无名指麻木 | 过多体重前移 | 把胶/双份把带/凝胶手套、抬升车把、缩短前伸量、车座水平 |
| 正中神经 | 拇指/食指麻木 | 腕管受压 | 同上 |

### 臀部/会阴

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 裆部麻木 | 车座中间压迫（男）、车座鼻端朝上 | 中空车座（男性）、车座水平、鼻端微朝下 |
| 尿路损伤/阴唇肿胀（女） | 车座外侧压迫 | 避免中空车座（对女性可能加重）、试不同车座 |
| 单侧臀部疼痛 | 腿长差异 | 垫片或鞋垫纠正 |

### 髂动脉

- 高强度骑行时腿部供血不足 → 不明原因功率下降
- 早期诊断至关重要（动脉壁变化不可逆）
- 预防：计时赛/铁三姿势髋关节闭合角度保持 35-40°

## AEIOU 诊断法

| 字母 | 含义 | 示例 |
|-----|------|------|
| **A** | Activity（训练变化） | 训练量突增、新类型训练 |
| **E** | Equipment（装备变化） | 新锁片/锁鞋/坐垫/车架可与症状发生时间相关，但不能据此断言固定比例因果关系 |
| **I** | Intrinsic（身体结构） | 腿长差异、骨盆不对称 |
| **O** | Other（其他因素） | 长途飞行、卧床、虫咬 |
| **U** | Unknown（未知） | 优化已知问题即可 |

**案例**：右膝痛最终发现右侧锁片松动

## 双腿长度差异线索

- 单侧臀部疼痛
- 双膝轨迹不同（短腿侧椭圆外展，长腿侧直上直下）
- 单侧背痛（骨盆三平面扭曲致骶骨偏移）
- 短腿侧小腿疲劳/脚尖朝下踩踏
- 单侧膝痛
- 3cm 以上需在骑行中考虑
- X 光诊断准确性仅 75-85%

## 角度定义与证据等级（使用前必读）

- 下死点膝关节角度存在两种记法：**髋-膝-踝内角**（伸直≈180°，比如145°）与「离完全伸直还差多少度」（比如35°）；两者互补：145°+35°=180°。读数必须注明是哪一种，不能混用。
- 这里的角度、把立长度、坐垫倾角均属于**常见筛查范围，不是临床安全阈值或对个人的保证值**；坐垫尺寸、柔韧性、旧伤、骑行用途及测量方法都会改变合理窗口。
- 有研究曾探索明显前倾坐垫对腰背痛的效果，但样本与适用条件有限，不能把10–15°下倾当作通用方案。参见 [2026系统综述](https://pubmed.ncbi.nlm.nih.gov/41705012/)（仅3项纳入研究）。
- 若换了新坐垫，应测量**实际承重面**、而不只是坐垫鼻端到车把的距离，优先观察骨盆稳定、手掌负重与局部压痛。
